# Публичная витрина smart_little_toons

Этот репозиторий предназначен только для небольшого публичного описания проекта.

- Соблюдай `PUBLICATION_POLICY.md`.
- Разрешены только `README.md`, `PUBLICATION_POLICY.md`, `AGENTS.md` и `.gitignore`.
- Не добавляй мультфильмы, изображения, аудио, сценарии, промпты, код или производственные документы, даже небольшие.
- Не используй `git add -f` и не расширяй разрешённый список без явного решения владельца.
- Прежняя история Storygro сохранена по решению владельца. Не возвращай производственные файлы в актуальную публичную версию через слияния, копирование или новые коммиты. Дальнейшая работа над роликами ведётся локально.
- Перед коммитом проверь список и содержимое всех добавленных файлов. Не публикуй локальные пути и внутренние сведения о производстве.
