# smart_little_toons

**Маленькие большие дела — футбольные истории для семейного просмотра.**

Белка София и енот Матвей знакомят зрителей с мировым футболом: его героями, неожиданными событиями и эмоциями больших матчей.

## Рубрики

- **Легенды футбола** — истории выдающихся игроков.
- **Футбольный вау-факт!** — необычные футбольные события.
- **Обзор матчей** — короткие эмоциональные истории игр. София и Матвей болеют за соперников, но остаются друзьями.

Смотреть выпуски: [Instagram · @smart_little_toons](https://www.instagram.com/smart_little_toons/reels/).
