# Выпуски smart_little_toons

Каталог историй, версий и материалов производства. [Главная страница](../../README.md) · [Рубрики и персонажи](../README.md) · [Правила производства](../../docs/how-to/football-series.md).

Версия для просмотра, успешная QA и опубликованный ролик — разные состояния. Проверяйте `review.yaml` и `VERIFICATION.json` внутри выпуска. MP4 и полные исходные медиа хранятся вне Git; здесь доступны сценарии, факты, промпты и небольшие превью.
