# Промо smart_little_toons

Две иллюстрации созданы встроенным **GPT Image** специально для публичного [README серии](../../README.md) по запросу Марины от 4 ноября 2026.

- [Футбольный мир Софии и Матвея](preview/football-world.jpg) — приглашение на вымышленный стадион.
- [Эмоции на трибуне](preview/matchday-friends.jpg) — два друга переживают игровой момент.

Это рекламные иллюстрации, а не кадры конкретных выпусков, реальные матчи или подтверждение сотрудничества с клубами. Изображения уменьшены до ширины 1100 px; каждый JPEG меньше 300 KiB. Полные оригиналы, промпты и производственные записи сохраняются отдельно.

Использование материалов серии обсуждается с Мариной через [Instagram Direct](https://www.instagram.com/smart_little_toons/) или [Issues](https://github.com/mermilova/Storygro/issues). Лицензия исходного движка не заменяет согласование использования героев и промо серии. [Политика публикации](../../PUBLICATION_POLICY.md).
